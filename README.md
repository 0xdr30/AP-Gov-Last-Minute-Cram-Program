# AP Gov Last Minute Cram Program

## About

I designed this program to help me cram for an ap gov vocabulary test. All of this was done the very night before the test, and totally didn't take all night to make when I could've just spent the whole time studying. I ended up getting a very great score, so please fork this for your own purposes if you wish. Be sure to change names within the program to match whatever you are cramming for.
